GAN — MNIST Image Generator

A Generative Adversarial Network (GAN) built with TensorFlow/Keras that learns to generate handwritten digit images using the MNIST dataset.

Overview

This notebook trains a GAN consisting of two neural networks:

Generator — takes random noise as input and produces fake MNIST-like images

Discriminator — learns to distinguish between real MNIST images and fake ones generated by the Generator

The two networks are trained together in an adversarial process until the generator produces convincing handwritten digits.

Requirements

Google Colab with TPU runtime (required)

TensorFlow / Keras

NumPy, Pandas, Matplotlib, Seaborn, scikit-learn, tqdm
